# Product roadmap

## Collaborative meeting → unit plan

Saved 3 November 2026 at Matthew's request. Deferred for a future session.

When teachers plan a unit together, let the LMS listen to their meeting,
transcribe the discussion, and use AI on the backend to implement their ideas
in the unit plan.

Intended flow: teacher starts a planning session → meeting transcription →
AI identifies planning ideas and decisions → creates or updates the unit plan
using the existing course planner.

This is a roadmap item only; meeting capture and automatic plan updates are
not part of the current appearance release.
