Ink Wire LMS classroom release release — 17 November 2026

Scope
Website first; Zoom is the next milestone before Mac packaging. An existing Mac
candidate remains available for checks. Windows explicitly deferred. Consolidates approved
Live Board appearance/composer work, independent lesson assessment, the native
Mac wrapper, and explicit Start lesson / End lesson controls.

Release boundary
The consolidated release is deployed to the existing inkwire-education Worker
and production domain on 17 November 2026. Zoom migrations 0019 and 0020 are
applied. Weekly meeting links work without OAuth; connected meeting controls and
automatic transcripts still await Zoom Marketplace configuration and real-account
acceptance. The main website was verified through the signed-in teacher UI.

Lesson lifecycle
Start and End controls are on the teacher class Timeline. Actual running/ended
state and timestamps are separate from timetable dates, published feedback and
Zoom state. Starting again preserves previous final versions. Cancelling a
scheduled class does not fabricate teaching history. Lessons with actual session
records cannot be removed or replaced through the course editor.

End closes linked, published class boards and saves their final versions. Boards
link through their explicit lesson selection or matching notebook lesson section.
Other lessons' boards, teacher drafts, archived boards and staff planning boards
are excluded. Each student receives a separate final reference page in the same
section; the live page and the student's notes are never overwritten. Final pages
refer to immutable snapshots, and timeline previews link to saved activities.
Already-open student board windows follow the saved result after polling. An
explicit historical snapshot window always stays on that version.

Partial notebook delivery leaves the lesson in Saving final work, with a Retry
control. Stable operation/snapshot/page IDs make retries safe. The lesson becomes
Taught only after all included board deliveries succeed. Closing posting directly
also saves a final version and distributes it. Protected/deleted notebook content,
storage limits and current class membership remain respected.

Storage and publication
Session state uses the existing private R2 store under lesson-sessions/{class}/.
Conditional writes reject concurrent teacher changes. Teacher role, class access,
origin, current account and request IDs are checked. Timeline projections contain
public session status and snapshot references, not private operation/history data.
Existing R2/D1 bindings are reused; this candidate needs no new database migration.
Ending a lesson does not publish assessment grades or call Zoom/transcript AI.

17 November follow-up — Live Board placement and calendar identity

Live boards now match the originating teacher section AND page, create missing
items, and append to existing student pages without replacing student writing.
The board header exposes End live board and Redeploy; closing freezes student
views against the saved final version. Venn creation asks for title, category
names and background, with optional instructions/posting options collapsed.
Wall/grid/other layouts are omitted from Venn creation.

Class colours are selectable in new-class setup and from the Class colours button
beside the class selector. Presets or dominant colours extracted locally from a
book-cover image persist with the course; the original cover image is not stored.
Calendar month/agenda cards and class selection share those colours, including
an accessible dark appearance. A Zoom video link on calendar cards opens the
participant meeting separately. Weekly links and lesson overrides use the same
resolution as the timeline; cancelled lessons omit the join action.

No database migration is required for this follow-up. Unit/API validation: 315
checks. Browser validation: all 23 workflows passed (the course-planner image
safety assertion was updated to allow the empty book-cover preview and rerun).
Worker production build/dry run passed; current bindings retained.
